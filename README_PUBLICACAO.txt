CENTRAL FINANCEIRA - 3 APLICAÇÕES
================================

Módulos:
1. /cielo/       - Gerador CIELO04
2. /difal/       - Conciliação DIFAL Banco Util x Dealer
3. /itau-dealer/ - Conciliação Itaú x Dealer

PUBLICAÇÃO NO NETLIFY
---------------------
Use este ZIP completo no MESMO projeto do Netlify.

Em um deploy manual:
1. Abra o projeto atual no Netlify.
2. Faça um novo deploy manual.
3. Arraste CENTRAL_FINANCEIRA_3_APLICACOES.zip.
4. A página inicial passará a mostrar os três módulos.

Não publique os ZIPs internos separadamente.

ESTRUTURA
---------
/
  index.html
  central.css
  /cielo/
  /difal/
  /itau-dealer/

Cada aplicação mantém seus próprios arquivos JS/CSS isolados.
